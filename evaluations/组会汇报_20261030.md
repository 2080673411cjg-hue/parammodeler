# 建筑点云基元识别与参数化重建阶段进展

汇报日期：2026年10月30日

工作进展截至：2026年10月29日

本周主要完成三方面工作：为插件增加模型与点云叠加的实时拟合残差显示，扩充十三类建筑基元数据并完成新一轮分类与参数回归训练，以及阅读建筑基元识别和参数化重建相关文献。

## 一 插件增加实时拟合残差显示

此前主要通过观察点云与模型的重叠情况判断重建效果。本次在三维视图角落增加拟合指标，调整模型尺寸或位置时，可以同时观察模型变化和数值变化，为交互微调提供定量参考。

| 指标 | 含义 | 作用 |
| --- | --- | --- |
| RMSE | 点云各点到模型三角网表面的最短距离的均方根 | 反映整体贴合程度，对较大偏差更敏感 |
| P95 | 95%的点到模型表面的距离不超过该值 | 观察大部分点的偏差范围，减少少量极端点对判断的干扰 |

距离按当前场景坐标单位计算；坐标单位为米时，指标单位也为米。评价针对模型表面，因此在线框显示模式下，计算对象仍是完整模型表面。

**这两个指标评价的是最终贴合程度，同时包含位置、形状和点云噪声的影响。** 它们可以辅助微调，但不能仅凭一个残差数值判断是对齐错误还是参数预测错误。

当前流程为：加载点云 → 分类与参数估计 → 模型自动叠加 → 手动微调尺寸或位姿 → 实时观察残差变化。

## 二 扩充数据并重新训练模型

### 1 数据规模

在已有多尺度合成数据基础上，为十三类基元追加样本，并对新增点云进行增强。每类数据由1000份扩充至2000份。

| 划分 | 扩充前每类 | 扩充后每类 | 当前十三类合计 |
| --- | ---: | ---: | ---: |
| 训练集 | 800 | 1600 | 20800 |
| 验证集 | 100 | 200 | 2600 |
| 测试集 | 100 | 200 | 2600 |
| 总计 | 1000 | 2000 | 26000 |

增强继续模拟噪声、少量离群点、局部缺失等情况，用于检验不完整点云下的识别与参数估计表现。

### 2 分类训练结果

完成分类模型 **v7** 训练，最佳模型出现在第87轮。

| 项目 | 结果 |
| --- | --- |
| 验证集准确率 | 99.92% |
| 测试集准确率 | **99.50%，2587/2600份正确** |
| 普通人字形与非对称人字形 | 各200份测试样本全部分类正确 |
| 主要剩余混淆 | 8份长方体被识别为L形 |
| 本轮训练耗时 | 约6小时46分钟，包含数据准备、验证和模型保存 |

已更新插件与远程推理服务的分类模型配置，并验证实际分类请求。此前被误识别的L形第978份点云，本次远程调用已正确识别为L形。

### 3 参数回归训练结果

完成十三类基元的参数回归 **v8** 训练，各训练100轮，累计耗时约 **10小时8分钟**，不含训练后测试。

将新旧模型放到原有每类100份、共1300份相同测试样本上比较，**64个参数中有63个参数的MAE降低**。其中部分代表性结果如下，尺寸单位为米。

| 模型与参数 | v7 MAE | v8 MAE | 误差下降 |
| --- | ---: | ---: | ---: |
| 圆柱半径 | 0.083 | 0.047 | 43.5% |
| L形总长度 | 0.436 | 0.303 | 30.6% |
| L形总宽度 | 0.478 | 0.317 | 33.6% |
| 普通人字形长度 | 0.661 | 0.499 | 24.5% |
| 非对称人字形屋脊长度 | 0.691 | 0.545 | 21.1% |
| 双人字形第一段长度 | 1.785 | 1.161 | 35.0% |

整体上，本轮扩充数据后的回归效果有所改善，但双人字形两段长度仍是明显薄弱项。圆塔底座高度的误差基本持平，没有出现与其他多数参数相同的改善。

上述回归比较使用合成数据记录的已知朝向，主要反映参数预测水平。实际自动重建还需要考虑点云判向和位置对齐。另外，本轮训练步数、验证集及数据加载方式也有变化，截顶类还涉及损失设置，结果暂不作为单独改变数据量的严格消融结论。

### 4 训练效率与插件验证

训练流程已加入点云内存缓存和多进程数据加载；针对训练前法向计算较耗时的问题，进一步增加了并行预处理，以及已用时间、预计剩余时间和总耗时显示。新增法向并行功能的完整训练提速效果将在后续训练中继续验证。

十三类回归已切换至v8配置，并通过插件中的点云与模型叠加检查典型样本。复测发现少量屋顶存在方向判断错误，已针对屋脊轴和外轮廓判向逻辑进行修正；修正后的完整推理与叠加效果仍需继续复测。

## 三 文献阅读与方法对照

重点阅读了以下两篇与当前课题直接相关的研究，并补充了解分类结合整体几何拟合的方法。

| 文献 | 主要方法 | 数据 | 对本课题的启发 |
| --- | --- | --- | --- |
| 张文元等，2023，基于3D基元拟合的复杂屋顶点云三维重建 | RANSAC提取屋面，拓扑图匹配识别基元，再通过约束优化求解形状与位姿 | ISPRS Vaihingen机载点云、senseFly无人机摄影测量点云 | 分类之后仍需确定形状和位置；可研究以网络预测作为几何优化初值 |
| Li与Shan，2026，Synthetic learning for primitive-based building model reconstruction from point clouds | 合成数据训练基于Transformer的分类与参数估计网络 | 十类基元、十万份合成建筑，另有六套真实点云验证 | 与当前技术路线最接近，重点借鉴多尺度数据设计和真实数据验证 |
| Zhang等，2021，Optimal Model Fitting for Building Reconstruction From Point Clouds | PointNet++分类，整体优化基元参数，再处理屋顶附属结构 | RoofN3D、senseFly | 为“网络识别结合几何参数优化”提供方法对照 |

文献[2]六套真实数据的完整名称及实验配置仍待全文核对。目前已确认其验证覆盖无人机、机载和星载平台。

**当前工作的定位：** 基于十三类参数化建筑基元，使用合成点云训练分类与参数回归模型，结合几何对齐及QGIS交互微调完成三维重建。后续需要用真实点云和分项实验，验证各环节的实际作用。

## 四 存在问题与下一步计划

| 存在问题 | 下一步安排 |
| --- | --- |
| 残差同时受到形状与位置影响，较难直接定位误差来源 | 在合成数据上分别固定真值形状或真值位姿，单独评价参数误差与对齐误差 |
| 双人字形长度、部分屋顶细节和少量方向判断仍不稳定 | 保留典型失败样本，分别检查分类、判向和回归结果，复测判向修正效果 |
| 当前主要结果来自合成数据 | 先选取能对应现有基元类型的真实单体建筑，开展小批量验证 |
| 新旧训练包含多个设置变化 | 固定测试集和训练设置，逐项比较数据量、尺度分布及训练策略的影响 |
