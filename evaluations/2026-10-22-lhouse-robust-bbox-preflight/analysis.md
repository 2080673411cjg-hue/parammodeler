# LHouse稳健水平bbox：实现与预检

日期：2026-10-22。仅完成实现、CPU测试和真实数据的特征检查，未执行GPU训练、真实网络推理或QGIS验收，未替换现有权重。

## 实验范围

- 使用现有LHouse 800/100/100数据，不重新生成或增强，不删除任何点。
- 保持五目标、标签、朝向规则、主干点坐标、法线、scale及原损失、选模标准不变。
- 仅将辅助bbox的XY跨度改为0.005/0.995分位数，Z仍为全点极差；体积和宽长比等派生量从新bbox一致计算。
- 不叠加corner loss。与上一轮corner_trial分开，直接对照axis_scale_trial。
- 不修改C++插件、分类器、其他类别回归、服务选模路径或任何现有checkpoint/config。

## 格式与兼容

新增训练开关--lhouse_robust_bbox。训练config与best checkpoint保存canonical_bbox_mode=lhouse_xy_quantile_005_995_v1；测试和单次推理使用权重中的字段。缺少字段的旧权重默认full，保持原极差特征。未知格式以及非L形/未canonical/legacy单位的错误组合在加载模型前拒绝，不静默回退。

输入仍须按原物理尺度契约声明physical或normalized。归一化点云先在其原坐标系计算分位数跨度，再乘metadata尺度；物理点云不再乘尺度。没有根据点云数值大小猜测单位。

服务协议没有新增字段，仍沿用input_coordinates；本机和远程均调用同一main_reg.py。新权重使用前必须同步新版main_reg.py，不能让旧推理脚本忽略特征版本。当前插件仍加载axis_scale_trial，没有提前部署未训练的新目录。

## CPU检查

14项辅助单位/特征检查、28项方向与训练管线检查、28项训练入口/服务选择检查，共70项通过。包含：

- 极端点用例中XY按分位数抑制远点，Z仍保留原全跨度；输入点本身不被修改。
- 物理/归一化表示的一致性，dataset和单次推理辅助量一致。
- 训练、验证、测试入口传递相同量法；保存config和best权重的字段正确。
- 旧checkpoint缺少新字段时保持原格式，临时CLI不能覆盖它。
- 新特征只改变辅助量，不改变送给网络的点坐标或目标。
- 非法类别/单位/特征版本拒绝，runner防止混用corner loss。
- 默认配方及其他类别不接收新的实验开关。

小模型CPU训练仅用于检查训练接线与字段保存，不作为PTv3准确率或GPU训练验证。

## 真实数据预检

从现有800份训练和100份验证记录构造新旧Dataset，未使用测试集选择分位数。旧full辅助量均值/标准差与当前axis_scale_trial的已保存配置吻合。

| 辅助量相对标签MAE（米） | full | 新XY分位数 |
|---|---:|---:|
| 训练长度 | 0.7257 | 0.1263 |
| 训练宽度 | 7.5040 | 0.1253 |
| 训练Z跨度 | 0.9391 | 0.9391 |
| 验证长度 | 0.7766 | 0.1138 |
| 验证宽度 | 7.2525 | 0.1274 |
| 验证Z跨度 | 0.9593 | 0.9593 |

这些是输入特征误差，不是网络预测误差。逐项断言新旧标签、Z辅助量、scale和metadata朝向一致。100份验证云分别按其存储归一化坐标和还原物理坐标计算新bbox，最大差3.814697e-6场景单位。

训练辅助量均值按bbox_x/bbox_y/bbox_z/scale/bbox_volume/aspect_ratio_xy顺序为：

```
full:   [28.71489, 17.51312, 5.67325, 16.01328, 3032.64844, 0.62872]
robust: [27.93898, 10.10980, 5.67325, 16.01328, 1627.73376, 0.39108]
```

完整数值和代码哈希见verification.json。新旧输入分布明显不同，必须另训新权重，不能只在旧权重推理时换成分位数。
