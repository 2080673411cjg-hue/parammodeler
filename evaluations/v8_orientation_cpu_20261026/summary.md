# v8 CPU 几何朝向补查（2026-10-26）

实际读取并调用真实几何函数：13 类 × 200 = 2600 份。接受朝向 1599，失败 1，明确跳过 1000。耗时 113.0 秒。

这只检查朝向预处理，不运行网络、不估计预测精度，也不评价平移定位或形状贴合。metadata 朝向仅用于计算角度误差；几何函数只接收真实点云、类别和 L 形开关。

按 v8 配置保留 canonical_align、lhouse_canonical、辅助单位、bbox_mode、目标转换及归一化；关闭法向、法向预计算和点云缓存。仅用进程内未使用的模型导入占位绕开模型依赖；所有几何函数和点云读取函数均为仓库原实现。

accepted 指算法标记 reliable 且数据集接受，不能等同于角度正确。SKIPPED_CLASS 单列，不计为旋转成功或失败。dataset_accepted 是构造器保留的样本数，含跳过旋转的类别。

**主要发现**

- 普通人字形：200份均接受，平均轴误差0.069°、P95为0.342°、最大0.5°，本批未发现90°错轴。
- 非对称人字形：200份均接受，其中3份接近90°错轴（sample_00907、sample_00972、sample_01086）。平均1.427°但P95仅0.5°，P95不能暴露这3份少数异常。
- 半圆柱屋顶：200份均接受，其中sample_00992轴误差90°；平均0.992°、P95为1.852°。
- 上述4份屋顶异常均为reliable=true、verdict=WEAK，当前数据集仍会接受。接受数并不保证轴方向正确；这些是几何朝向模块的实测异常，不能归因于v8网络权重。
- L形：199份接受、1份明确失败；接受样本平均0.576°、P95为2°、最大3°。失败为sample_00978，三个屋顶角点和一个明显缺角的支持条件未满足。
- 长方体：有2份接近90°的轴差，均为近正方形；其中sample_01015长宽同为7.2米，90°可为相同形状，不能一律当作模型对齐错误。凹陷长方体另有1份近正方形外框的89°轴差。
- 金字塔屋顶：sample_01087误差41.5°，算法仍给PASS；其余类别的低P95不能用来排除这类个别异常。全部8份>10°异常见axis_outliers_gt10.json。
- 截顶金字塔：200份接受，平均0.080°、P95为0.5°、最大0.544°。
- 双人字形200份均返回SKIPPED_CLASS，不能据本次检查宣称它的朝向通过。四类圆形基元800份也明确跳过，未混入旋转成功统计。

本轮优先暴露的是少量屋顶错轴及低置信度结果仍被接受的问题。本次不更改处理规则，也不判断网络输出、分类正确率、平移对齐或拟合残差；这些结论均需另外测试。
