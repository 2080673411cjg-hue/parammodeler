# 凹陷长方体：外框水平定位

日期：2026-10-20。本地未发布源码。只改外框XY，不重训、不更换权重、不构建插件DLL。

## 修改方法

1. 高度仍由原外侧顶缘方法确定；到最后生成对齐目标时才改XY，不改变原Z参考。
2. 水平回退采用完整点云的稳健轮廓，不用稀疏底部切片决定左下角。
3. 筛选原顶面高度附近的点，沿每条边分8段；至少6段有足够点、最外缘位置较一致时，取分段最外侧点的中位数细化边界。只允许有支撑的小幅向外修正，不按单个最小点或内槽边缘移动。
4. 复用既有平面拟合，在顶缘以下识别竖直外墙；若候选墙外侧还有足量顶面点，拒绝把它作为外墙，避免内槽壁干扰。用可靠外墙细化角点，没有可靠墙的方向保留顶缘/完整轮廓结果。

没有改模型尺寸、朝向、内槽识别算法或手动微调规则。外框完成定位后仍单独定位内槽；内槽偏移是相对新外框原点的坐标，需要正常换算，不等于强行移动内槽的世界位置。预测尺寸下容纳空间不足时的原有合法范围限制仍保留。

## 对照范围

沿用13类各100份增强点云、原预测（圆塔v5，其余v4 canonical）、真实类别及metadata朝向，四组共5200条；额外检查1300份原始点云真值回建。这里只验证固定朝向下的几何定位，不是未知朝向推理、真实点云精度或QGIS交互验收。

最新增量应与 `2026-10-20-alignment-first-gable/` 比较，对照明细保存在 `comparison-first-gable.csv`；此前四轮结果不覆盖。默认 `comparison.csv` 与v2.4.0相比，包含前面几轮累计修改，不能都归因于本轮。

## 同数据结果

每类100份，单位米。位置P95是逐样本平移误差的95%分位，不是视图中的点到面P95。

| 真值形状自动定位 | 中位数：之前 → 之后 | P95：之前 → 之后 | 改善/变差/不变 |
|---|---:|---:|---:|
| 外框水平误差 | 0.3418 → 0.1778 | 0.6683 → 0.5429 | 99/0/1 |
| 外框高度误差 | 0.0051 → 0.0051 | 0.0187 → 0.0187 | 0/0/100 |
| 点到面RMSE | 0.1568 → 0.1434 | 0.2604 → 0.2554 | 92/7/1 |

| 原预测形状加自动定位 | 中位数：之前 → 之后 | P95：之前 → 之后 | 改善/变差/不变 |
|---|---:|---:|---:|
| 外框水平误差 | 0.3418 → 0.1778 | 0.6683 → 0.5429 | 99/0/1 |
| 外框高度误差 | 0.2008 → 0.2008 | 0.6992 → 0.6992 | 0/0/100 |
| 点到面RMSE | 0.2193 → 0.2127 | 0.3881 → 0.3811 | 81/18/1 |

内槽世界角点的XY误差中位数仍约0.0536米，P95约0.1080米；逐样本误差差异小于0.000001米，属于浮点舍入级别。两组内槽顶面Z误差均逐样本不变。没有修改内槽长宽深度或定位方法。

83份采用分段顶缘，59份采用外墙细化，其中43份两者均采用；1份保留完整轮廓。最初仅细化可见外墙时，水平中位数仅改善约0.005米，因此补充了缺墙方向的分段顶缘估计。

改善不代表已经完全对齐：水平P95仍约0.543米。真实定位改善也不保证预测模型的表面残差逐份下降；18份组合RMSE上升，最大约0.061米，仍保留在明细中。

最终5200条记录均有效，52组各100份；其余十二类4800条记录与上一轮逐字段完全一致。2600条不含自动定位的baseline/shape残差与覆盖率和v2.4.0一致，1300份原始真值回建均低于0.000001米，源码哈希与最终版本一致。临时独立编译文件已清除；没有构建插件DLL或进行QGIS交互验收。

## 限制与验证

- 分段顶缘需要有足够的外轮廓观测；严重缺边、密度不均或裁剪导致的真实边界缺失，不能保证恢复正确位置。各段支撑不足或边缘散布过大时回退，不根据预测长宽强行补角点。
- 稀疏、噪声较大的顶缘仍会有边界偏差。该方法不是精确轮廓分割，也不承诺每份点云的残差都改善。
- 这批合成数据用于开发回归，不能作为独立留出集的论文泛化结果。

独立检查包含完整外墙、缺一面外墙时拒绝附近密集内槽壁、密集槽底干扰、仅顶面和稀疏回退、顶缘噪声及少量外侧离群点；保留原对齐与坐标转换检查。

用户自行编译、重启QGIS，在参数估计窗口对同一份凹陷点云重新执行“一键完成”；几何校正保持关闭即可，不需要重新训练或重启Ubuntu服务。复现运行 `scripts/evaluate_alignment.ps1`，默认写入本目录；`outer-rim`与`outer-walls`来源标记分别表示顶缘细化及外墙细化被采用。
