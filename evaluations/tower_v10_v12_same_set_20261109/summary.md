# 圆屋v10与v12原损失同集预测

本次同集比较中，v12原损失版的8/8项参数MAE低于v10，统一标准化的加权参数误差下降21.7%。三段等权剖面距离下降22.6%，200份中有130份整体剖面距离更小。

两套权重均通过实验室现有 /regress 服务，对冻结的同一200份v2增强测试点云分别预测，共400次真实请求。每次核对返回的模型目录、输入哈希、辅助特征单位及八个有限参数。类别固定为圆屋，未测试分类或模型位置对齐。

几何约束不满足的原始预测：v10=1/200，v12=0/200；未从误差统计中排除，具体文件保存在summary.json。

本次结果反映整套v10与v12训练权重在同一新测试集上的表现；不能单独把差异归因于某一处代码修复。单云服务与训练后的批测试在数值上可能不同，本对照对两套权重使用同一服务协议。

实验目录保留原始响应、冻结点云和本机参考权重及配置哈希。仓库随附统计汇总。服务核对了实际模型目录，远程权重文件哈希尚未核验。
