# 自动对齐优化：与 v2.4.0 对照

日期：2026-10-20。未发布的本地源码修改；没有重新训练、修改权重或构建插件 DLL。

## 范围与校验

- 基线为已发布 v2.4.0 的 `evaluations/2026-10-20-alignment/`；该目录未覆盖。
- 固定13类各100份增强点云，使用原测试预测（圆塔v5，其余v4 canonical），固定真实类别和 metadata 朝向，四组共5200条结果。不是未知朝向完整推理或实际QGIS窗口验收。
- 对比前后预测、配置和 metadata 哈希一致；2600条不包含自动定位的 baseline/shape 距离与覆盖率均保持一致。原始点云回建校验沿用1300份真值模型/真值位姿检查。
- 统计属于同一合成数据集上的开发回归对照，不作为新的独立测试集或真实点云泛化精度。
- 只改自动平移参考：保持网络输出形状，保留内槽已有独立定位；不通过几何校正开关修正尺寸。

## 位置误差

使用真实形状测定位，排除预测尺寸干扰。每类100份，单位米。P95是逐样本定位误差的95%分位，不是插件浮窗中点到面的P95。

| 项目 | 中位数：之前 → 之后 | P95：之前 → 之后 |
|---|---:|---:|
| 圆柱水平 | 0.222 → 0.010 | 0.451 → 0.029 |
| 圆锥圆柱水平 | 0.362 → 0.008 | 2.123 → 0.025 |
| 穹顶圆柱水平 | 0.501 → 0.010 | 1.234 → 0.028 |
| 半圆柱屋顶水平 | 0.556 → 0.099 | 1.571 → 0.271 |
| 半圆柱屋顶竖向 | 0.000 → 0.009 | 0.378 → 0.029 |
| 凹陷长方体竖向 | 0.485 → 0.005 | 0.681 → 0.019 |
| 截顶金字塔竖向 | 0.467 → 0.043 | 1.132 → 0.155 |
| 金字塔竖向 | 0.272 → 0.034 | 0.480 → 0.080 |
| 普通人字形竖向 | 0.174 → 0.044 | 0.362 → 0.173 |
| 非对称人字形竖向 | 0.196 → 0.034 | 0.936 → 0.690 |

圆柱、圆锥、穹顶和半圆柱的水平定位均为100/100份改善；凹陷和金字塔的竖向定位均为100/100份改善。普通/非对称人字形各92份竖向改善、8份变差；截顶94份改善、6份变差。

半圆柱原中位数为零，不等于原拱顶识别已经正确：原流程大多数采用模型自身檐口偏移回退，真实尺寸实验中会抵消参考高度。本轮独立剖面定位带来约9毫米中位误差，但明显降低尾部误差；54份竖向误差增加，最大增加约0.054米，不隐去这个权衡。

| 模型 | 之前 → 之后（米） | 改善/变差/不变（份） |
|---|---:|---:|
| 圆柱 | 0.137 → 0.098 | 100/0/0 |
| 圆锥圆柱 | 0.215 → 0.125 | 100/0/0 |

| 半圆柱屋顶 | 0.415 → 0.223 | 87/13/0 |
| 凹陷长方体 | 0.411 → 0.219 | 99/1/0 |
| 截顶金字塔 | 0.408 → 0.228 | 94/6/0 |

真实定位更准不保证每份预测形状的残差都下降：预测尺寸误差有时被旧定位偏差偶然抵消。本轮不通过选择更小残差来强行恢复错误位置，也不据四组残差相减来分配独立误差贡献。

## 修改内容

1. 凹陷外框：外侧顶缘支撑高度替代最高点，避免槽底/高噪声点误导。
2. 屋顶：复用现有平面拟合，从靠近外侧的屋面带外推檐口，拒绝竖墙、水平平台和弱候选，失败保留原底部参考回退。
3. 圆形：低层可见圆弧估计圆心，稳健重拟合并检查残差、支撑和角度覆盖；不写回预测半径。失败使用完整轮廓中心，不用遮挡底片中心。
4. 半圆柱：从拱顶YZ剖面估计侧边与檐口，初始高度筛选后再以径向内点重拟合，避免截取带来的扁平偏差；不写回长度、宽度或墙高。

没有增加训练目标、UI参数、QGIS核心修改或生产CPP文件。修改集中在现有对齐几何头文件、语义目标估计和显示点云对齐缓存；评测调度同步调用同一几何函数。

## 未解决与验证

- 长方体、L形、圆塔、双人字的既有定位规则未变，组合结果与基线相同；圆塔水平误差中位数仍约0.304米。L形与凹陷外框的部分水平偏差也未由本轮处理。
- 非对称人字形仍有较大的竖向尾部误差，P95约0.690米；不能宣称全部屋顶均可靠。
- 无 metadata、方向错误、非Z-up或真实建筑不符合基元假设的情况，不能直接套用本表精度。
- 通过缺面/离群点、顶缘与槽底、截顶平台、短弧/直线退化、圆心平移和半拱检查，以及原平面拟合/坐标转换回归检查；插件源文件语法检查通过。没有编译插件DLL或做完整QGIS交互验收。

用户编译并重启QGIS后，对同一点云重新执行估计/一键完成，让新版定位重新运行；不需要重训或因为此次修改重启Ubuntu推理服务。保持几何校正关闭即可验证本轮改动。建议先看凹陷/截顶的高度、三类圆形的中心和半圆柱侧边，并同时保留参数误差的判断。

复现：PowerShell执行 `scripts/evaluate_alignment.ps1`。`comparison.csv`包含前后中位数、P95、逐样本数量和最大变差量；`per_sample.csv`保留点云文件名、参考点来源、内槽状态与全部残差。原基线版本可按Git标签 `v2.4.0` 查阅。
